# Final Build Report — v0.4.1

PixelPilot is an owner-only personal multimodal assistant that rents temporary Vast.ai GPUs only when needed.

Runtime: `Telegram -> Controller -> Vast.ai -> vLLM -> Qwen2.5-Omni-7B`.

Capabilities: text conversation, image understanding, audio/voice understanding and short follow-up context. Image generation, FLUX, ComfyUI, image workflows, seeds, ratios and batches are not part of the current project.

The economy profile targets 48GB+ GPUs, 80GB disk, 8192-token context and a default search cap of $0.80/hour. This replaces the initial Qwen3-Omni 30B / 80–96GB profile that was too expensive for personal use.

No System Prompt or Developer Prompt is generated by PixelPilot. Tests enforce that text/media requests are constructed from user-provided content only.

A real Vast GPU run remains the final acceptance step for cold-start time, VRAM headroom, Arabic quality, image understanding and Telegram OGG audio compatibility.
