# Final Build Report — v0.4

PixelPilot has been refactored from an on-demand image generator into an owner-only personal multimodal assistant.

Runtime: `Telegram -> Controller -> Vast.ai -> vLLM -> Qwen3-Omni`.

Capabilities: text conversation, image understanding, audio/voice understanding and short follow-up context. Image generation, FLUX, ComfyUI, image workflows, seeds, ratios and batches were removed.

No System Prompt or Developer Prompt is generated by PixelPilot. Tests enforce that text/media requests are constructed from user-provided content only.

A real Vast GPU run remains the final acceptance step for cold-start time, VRAM headroom and Telegram OGG audio compatibility.
